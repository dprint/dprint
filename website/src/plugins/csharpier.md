# CSharpier Plugin

Wrapper plugin that formats C# and XML code via [CSharpier](https://github.com/belav/csharpier).

Formats the same files as CSharpier: .cs and .csx files as C#, and .csproj, .props, .targets, .slnx, .config, .xml, .xaml, and .axaml files as XML. Like CSharpier, it skips generated files (ex. _\*.g.cs_, _\*.designer.cs_, or a C# file starting with an `<auto-generated>` comment) unless `"includeGenerated"` is `true`.

## Install and Setup

In your project's directory with a dprint.json file, run:

```shellsession
dprint add csharpier
```

This will update your config file to have an entry for the plugin. Then optionally specify a `"csharpier"` property to add configuration:

```json
{
  "csharpier": {
    // csharpier's config goes here
  },
  "plugins": [
    "npm:@dprint/csharpier@x.x.x"
  ]
}
```
