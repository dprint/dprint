# CSharpier - Configuration

The `lineWidth`, `indentWidth`, `useTabs`, and `newLineKind` properties use the global configuration when not specified, and may be specified for only C# or XML files by prefixing them with `csharp.` or `xml.` (ex. `"csharp.lineWidth": 120`). CSharpier's configuration files (_.csharpierrc_ and _.editorconfig_) aren't read.
