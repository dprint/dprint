The plugins to prefer have nothing to do with a config file, so a plugin the
one in the directory already has is selected like any other and the config
file is left alone.

-- file: /notes.txt --
-- file: /dprint.json --

  "plugins": [
    "https://plugins.dprint.dev/test-plugin.wasm"
  ]
}
-- args --
init --preferences
